# 저장 대기 중 편집·이동 시험의 독립 검토

제품 구현자 `/root/flow_trial`의 최종 파일을 부모 `/root`가 별도 Chrome
프로필에서 실행하고 JSON·소스·렌더링 이미지와 대조했다. 같은 모델의 별도
문맥에 의한 AI 검토이며 사람의 검수·사용자 연구는 아니다.

`check-interruption.mjs`로 원본과 결과 제품에 같은 입력을 제공했다. 추가 입력,
그 입력의 후속 저장, 저장 성공 전 다른 메모 선택, 저장 실패 전 다른 메모 선택의
네 관찰에서 원본은 18개 데이터/조작 단언 중 16개 통과·2개 실패,
결과 제품은 18개 모두 통과했다. 원본의 실패 2개는 다른 메모로 이동한 뒤 저장
실패가 현재 메모의 새 제목·본문을 덮은 것이다. 검사기는 관찰한 값을 JSON에 보존한다.
시간 관찰은 작은 로컬 fixture의 기존 30ms 저장에 대한 150ms 대기이며,
실제 네트워크 서비스의 시간 계약이나 OS 입력 순서 검증은 아니다.

별도로 기존 `search-editor-v3` 브라우저 수집기를 결과 제품에 실행해 필수 행동
검사 16개가 모두 통과했고 실행 예외·수집 오류·미실행은 0개였다. 이 결과는
추가한 중단 시나리오와 합쳐 새 공식 suite 버전으로 선언하지 않았다.

문구는 숫자 단언과 별도로 확인했다. 원본은 현재 입력과 저장된 값이 다른데도
“메모를 저장했습니다.”라고 표시했다. 결과 제품은 이전 스냅샷만 저장했음을
설명하고 “이후 변경사항은 아직 저장하지 않았습니다.”라고 알린다.
다른 메모로 이동한 경우에는 원래 메모의 성공·실패가 현재 메모의 초안과
“아직 저장하지 않은 변경사항이 있습니다.” 피드백을 덮지 않는다.

직접 열람한 결과 이미지 6개(압축 안의 경로):

- `result-evidence/edit-during-save.png`
- `result-evidence/switch-before-success.png`
- `result-evidence/switch-before-failure.png`

1280px에서 기존 하늘 브랜드·옅은 바탕·목록/편집기 구조가 유지되며,
375px에서 목록과 편집기가 세로로 배치된다. 오류 문장은 줄바꿈돼 읽히고,
실제 Tab으로 도달한 “다시 저장” 버튼의 초점 테두리가 보인다.
`DESIGN.md`와 CSS의 기존 토큰 값은 유지됐으며 새 현재 메모 표시가 기존
action/canvas 역할을 재사용한다. 긴 제목은 원래 단일행 input의 내부 스크롤
동작을 유지한다. 실제 스크린리더와 물리 기기, 실제 한국어 IME는 관찰하지 않았다.

제품 작성자가 보고한 자체 검사 47개는 `agent-output.md`와 작성자 자료에 별도로
보존한다. 부모가 실행한 위 검사와 합산하지 않는다. 새 규칙이나 스킬 버전을
평가한 비교 쌍은 없으며, 현재 지침이 이 추가 과업을 처리한 한 사례다.
따라서 이 결과만으로 스킬 지침을 늘리거나 일반적인 우월성을 주장하지 않는다.
