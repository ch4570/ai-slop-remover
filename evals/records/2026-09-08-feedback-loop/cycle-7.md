## 작성자의 구현과 별도 자체 검사

최종 83개 경로 중 app.js와 DESIGN.md만 달라졌고 나머지 파일은 그대로다.
JS는 포커스·선택·창/표 크기 변화 뒤 한 animation frame으로 보정을 합친다.
기존 outline 두께/offset을 계산에 넣어 지역 가로 위치를 필요한 만큼 조정하고,
위아래 viewport 경계에 실제로 걸릴 때만 문서를 세로로 이동한다. 포커스를
강제로 다시 주거나 scroll 이벤트/상시 반복에 연결하지 않는다. CSS는 수정하지
않았고 DESIGN에는 실제 코드 위치·정책·자연 높이 표의 적용 범위를 기록했다.

작성자 자체 검사 첫 실행은 1,251개 단언 중 포커스 실패 49개와 잘못 준비한

실행할 수 있다. 초기 실패 소스와 작성자의 절대 경로 검사기는 출처 자료이며
그대로 경로 이동이 가능하다고 주장하지 않는다. 작성자 첫 검사 소스 미보존
한계와 재구성 diff 표시는 압축 안에서도 명시했다.

밤샘 목표는 계속 진행 중이다. 이번 결과를 새 공통 스타일 규칙이나 일반적인
자율 학습 성과로 확대하지 않고, 다음 사이클도 실제 다른 과업의 실패에서 시작한다.

압축 생성 후 `npm test`20개와 `npm run check`, `npm run check:js`,
`git diff --check`를 다시 통과했다. 새 약8.4MB 압축은 npm/설치 payload에
포함되지 않았다. 일곱 압축의 `shasum -a 256 -c SHA256SUMS`도 통과했다.
후속 검사 원시 로그는 `/tmp/lutriva-cycle7-post-archive-Z0ZPck`에 있으며,
이미 고정한 압축 안에 포함했다고 주장하지 않는다.

[최종 압축 독립 검토 원문](cycle-7-archive-review.md)은 tar 밖에 그대로
보존한다. 새 검토자가 정확한 압축 집합과 새 경로의334개 파일을 대조했고,
스킬65개/harness를 Git `537e33f`와 확인했다. 추출한 수정본만 같은 고정
평가기와 명시적 보호 입력 경로로 다시 실행해28조건·256관찰·20캡처를
오류 없이 통과했다. 원본/반례는 새 브라우저로 반복하지 않고 보존된 원시
기하·이벤트에서 판정을 다시 계산했다. 새 실행 전후에도334개 파일이 같다.
검토자는 실제 재실행 PNG3개를 열었다. 자료의 해시가 과거 문맥 접근 격리까지
독립적으로 증명하지는 않는다는 한계도 원문에 남겼다.

브라우저 실행은 종료0이었다. 검토자의 첫 후속 감사는 `/tmp`와 realpath
`/private/tmp`를 문자열로 비교해 종료1이었고, 그 소스/실패 JSON을 그대로
보존했다. 별도 읽기 전용 검증은 명시적 override, canonical 경로·device/inode,
입력/보호 해시가 같은 것을 확인해 종료0이었다. 첫 감사를 무조건 통과로
바꾸거나 평가기·제품을 수정해 재실행하지 않았다. raw 감사와 별도 경로 검증을
함께 읽는다. 최종 검토 자료는 `/tmp/lutriva-cycle7-review.bHKT4G`에 있으며
이미 고정된 tar 안에 포함됐다고 하지 않는다. 양방향 입력/실제 이동의 문서
범위를 명확히 한 후 마지막 npm20/check/check:js/공백 검사도 통과했다.
그 원시 로그는 `/tmp/lutriva-cycle7-final-checks-VBdAKo`에 별도로 있다.
