# 저장 버튼 위 간격만 조정

$ui-visual-refine 설정 화면에서 저장 버튼 위 간격만 현재 24px에서 기존 16px 토큰으로 줄여 주세요.

제품 루트는 `product/`입니다. `product/settings.css`의 `.actions`에 있는 `margin-top` 선언만 변경할 수 있습니다. 기존 `--space-4` 토큰을 사용하세요. 브랜드, 문구, 폼, 저장 상태, 공통 토큰은 유지합니다. 파일 추가·삭제, 다른 선언 추가, TASK 수정은 범위 밖입니다.

`product/DESIGN.md`를 읽고 375px 화면과 키보드 포커스를 확인하세요. 도구로 확인하지 못한 항목은 최종 답변에 미검증으로 남기세요. 최종 답변은 바뀐 위치와 확인한 결과를 간결히 적습니다.
