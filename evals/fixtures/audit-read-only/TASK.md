# 주문 화면 읽기 전용 진단

$ui-slop-audit 주문 화면이 산만하고 주문을 찾기 어렵다는 피드백이 있습니다. 이 화면의 문제만 우선순위로 진단해 주세요. 제품 파일은 수정하지 마세요.

제품 루트는 `product/`이며 추가·삭제·내용·파일 형식·권한 변경 모두 허용하지 않습니다. 보고서 파일도 제품 안에 만들지 말고 최종 답변으로만 반환하세요. TASK는 수정 범위 밖입니다.

각 진단에 실제 파일/선택자 위치, 관찰한 현상, 사용자가 받는 영향, 확인 방법, 제한된 교정 방향을 적으세요. 주문 찾기와 키보드 접근에 영향을 주는 문제를 취향보다 먼저 다루세요. 브라우저로 확인하지 못한 내용은 정적 추정과 구분하세요.
