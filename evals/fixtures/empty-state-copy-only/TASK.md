# 검색 결과 없음 문구만 수정

$ux-writing 한국어 검색 결과 없음 문구만 더 자연스럽고 유용하게 다듬어 주세요. 필터 초기화 기능이나 초기화 버튼은 현재 없습니다. 사용자는 검색창의 검색어를 바꿀 수 있습니다.

제품 루트는 `product/`입니다. `product/locales/ko.json`의 `empty_title`, `empty_body`, `empty_name` 문자열 값만 변경할 수 있습니다. 기존 키와 각 문자열별 보간 변수 구성을 유지하세요. `empty_title`·`empty_name`의 `{query}`를 보존하고 `empty_body`에는 새 변수를 추가하지 않습니다. 다른 locale, 아직 항목이 없는 상태, HTML·ARIA 연결과 동작은 유지하세요. 파일 추가·삭제와 TASK 수정은 범위 밖입니다.

표시 문구와 접근 가능한 이름의 의미를 맞추세요. 결과 없음과 실제 검색어 변경 후 결과 복구를 확인하고, 브라우저·보조기술로 확인하지 못한 부분은 최종 답변에 구분해 적습니다.
