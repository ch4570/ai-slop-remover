# Visual clarity serves a task

- Preserve brand and behavior as constraints; choose structure from the task.
- A focused spacing correction can be complete without a design system rewrite.
- Prefer deletion, grouping, and existing tokens to new wrappers or decorative layers.
- Keep useful density. Whitespace should reveal relationships, not push work out of view.
- Readability, content order, and action access must survive narrow screens and long text.
- Use canonical [art-direction guidance](../../ui-craft-bundle/references/art-direction.md); no color, font, card, or radius is universally forbidden.
- Treat each rendered inspection as evidence for the next change, not an invitation to endless revisions.
