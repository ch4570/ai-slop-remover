# UI Craft Bundle 사용 안내

이 스킬은 기존 `$ui-craft-bundle` 호출을 유지하며 디자인 방향, 상태, 모션, 웹·네이티브 구현과 실제 검수를 연결합니다. 필요한 참조만 읽습니다.

```text
$ui-craft-bundle
현재 화면의 핵심 작업이 더 명확하고 편해지도록 개선해줘.
기존 브랜드와 스택을 유지하고 주요 조작이 실제 결과로 이어지게 해줘.
실제로 확인한 화면·동작과 미검증 범위를 구분해서 알려줘.
```

AI Slop Remover 전체 세트를 설치했다면 `$ai-slop-remover`로 시작하거나 진단·시각 정리·흐름·문구·검수 스킬을 독립적으로 호출할 수 있습니다. 이 단일 패키지만 설치해도 기존 흐름은 작동합니다.

설치기는 설치된 스킬 폴더에 포함되지 않습니다. 소스 저장소 또는 배포 ZIP의 루트에서 `python3 install.py --repo "/path/to/project" --agent codex`를 실행하면 전체 세트를 설치합니다. Claude Code는 `--agent claude`를 사용합니다. `--dest "/path/to/skills/ui-craft-bundle"`는 이 단일 패키지용입니다.

기존 설치를 자동으로 덮어쓰지 않습니다. 새 버전으로 바꿀 때는 기존 폴더를 검토·백업해 옮긴 뒤 다시 설치하세요. 설치 성공, 호스트 발견, 실제 스킬 실행은 별도로 확인해야 합니다.

지침 적용에 Figma·외부 디자인 스킬·MCP 서버는 필수가 아닙니다. 실제 제품 검수에는 프로젝트 실행 환경과 호스트가 허용한 도구가 필요합니다. 빌드 통과만으로 화면이나 동작을 확인했다고 보고하지 않습니다.
