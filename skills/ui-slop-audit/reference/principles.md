# Diagnose friction with evidence

- Judge a screen by the user's job and the product's constraints. “AI slop” names the requested cleanup, not a provable author identity.
- Preserve domain meaning and deliberate brand choices. Common patterns can be the clearest solution.
- Make each finding traceable to an observed element and a task consequence. Mark inference and preference explicitly.
- Prefer the smallest correction that removes supported friction; do not invent work to fill a checklist.
- Keep an audit read-only and separate its recommendations from authority to implement.
- Use the shared [art-direction criteria](../../ui-craft-bundle/references/art-direction.md) as context, not a mandatory aesthetic.
