# Predictable response creates smooth UX

- Describe the outcome before choosing an interaction or animation.
- Keep input, drafts, focus, and user intent intact across waiting, failure, and interruption.
- Let real state determine feedback. A displayed success message is not evidence of persistence.
- Preserve the established state owner and navigation architecture; repair the narrow flow first.
- Animation is optional. Immediate, understandable state changes can provide the best experience.
- Reuse the shared [interaction](../../ui-craft-bundle/references/interaction-design.md) and [motion](../../ui-craft-bundle/references/motion.md) contracts instead of inventing universal effects or timing gates.
- Prove the affected result and recovery path with outcome evidence; disclose unavailable runtime checks.
