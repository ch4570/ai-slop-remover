# 검증 기록

## 범위 평가 harness (이슈 #6)

검증일: 2026-09-07. 네 독립 사례의 fixture·고정 TASK·허용 수정 범위와 외부 판정 기준을 추가했다. [실행 계약과 재현 명령](https://github.com/ch4570/lutriva/blob/main/evals/README.md#four-bounded-scope-trials-suite-version-1)에 source 검사, 브라우저 관찰, 별도 의미·화면 검수의 경계를 기록했다.

- `narrow-spacing`, `audit-read-only`, `empty-state-copy-only`, `master-page-consistency`를 각기 분리된 제품 복사본으로 실행한다. 기존 `search-editor-v3`와 결과 schema 1은 유지한다.
- 정상 대조군에서 시작해 읽기 전용 파일·루트 symlink 변경, 공통 토큰과 지역 브랜드 덮어쓰기, 저장 값 손실, 보간 변수·ARIA 손실, 없는 필터 초기화 안내, 디자인 기록 불일치를 각각 검출했다. 복구 안내의 문자열 검사는 정해진 변이만 탐지하며 문구 의미 전반의 통과 근거가 아니다.
- Chrome 연결부 추출 후 기존 18개 회귀 검사가 통과했다. 새 브라우저 대조군은 네 사례의 실제 저장·검색·행 동작, 계산된 스타일, 접근 가능한 이름을 수집한다. 화면 캡처의 존재를 시각 검수로 취급하지 않는다.
- 필수 관찰이나 검수가 빠지면 `not-run`/`incomplete`로 남긴다. 이미 관찰한 구체적 실패는 나중의 관찰 누락으로 지우지 않는다. 반복 결과는 여덟 비교 쌍별로 표시하며 평균 점수로 회귀를 숨기지 않는다.

이 절은 harness 검증 범위다. 실제 16개 native 실행과 8개 비교 결과는 별도 기록이 필요하며, harness 통과만으로 이슈 #6의 실행 평가가 완료되거나 스킬 품질이 개선되었다고 판단하지 않는다. snapshot을 직접 읽힌 실행은 `snapshot-direct`로 기록하고, 설치된 호스트의 명시적 호출과 자동 발견은 각각 미실행으로 구분한다. 현재 로컬 harness 검증은 macOS/Node 25.2.1/Python 3.14.7과 설치된 Chrome에서 수행했다. Node 20/Python 3.9 기본 런타임, Node 22 이상의 선택적 Chrome 검사와 기존 CI 행렬은 유지하며 새 의존성은 추가하지 않았다.

## 2.2.0 브랜드와 CLI 호환성

검증일: 2026-09-07. Lutriva 이름, README·배너, npm 패키지와 CLI 별칭을 반영했다. `skills/`의 지침은 2.1.0과 동일하다.

- Python 전체 80개·npm CLI 7개 테스트 통과. 새 `lutriva`와 기존 `ai-slop-remover`를 각각 실제 설치한 뒤 `--version`·`--list` 출력이 같은지 확인했다. 새 명령이 없던 기존 패키지에서 확장한 검사가 실패하는 것도 먼저 확인했다.
- 새 임시 npm 캐시에서 로컬 tarball을 `npm exec --offline`으로 실행해 `lutriva --version`이 2.2.0을 반환하는지 확인했다. 레지스트리 설치와는 별개다.
- 배포 목록 65개 파일의 해시와 링크·의존성을 검증했다. npm tarball은 manifest·package.json·CLI를 포함해 68개 파일이며 배너와 브랜드 안내도 포함한다. 독립 정적 검토에서 누락된 파일이나 호환성 문제는 발견되지 않았다.
- GitHub Markdown API가 렌더링한 두 README를 별도 Chrome의 로컬 미리보기에서 확인했다. 1280px 밝은·어두운 배경과 375px 화면에서 배너·본문·설치 안내를 검수했고, 모바일 설치 표를 두 열로 줄여 호출명이 잘게 끊어지는 문제를 고쳤다. 페이지 가로 넘침·내부 앵커와 키보드로 상세 안내를 여는 동작을 확인했다.

화면 검수는 GitHub Markdown HTML에 로컬 미리보기 스타일을 적용한 결과다. 인증된 GitHub 애플리케이션 전체나 실제 휴대 기기를 검사한 것은 아니다. npm 게시, Windows 실행, 새 모델 비교 평가는 이번 검증에 포함하지 않았다. 아래 2.1.0 결과를 브랜드 변경의 UI 품질 향상 증거로 해석하지 않는다.

프로젝트에 의존성을 추가하지 않았다. 공식 validator는 기존 SkillEvaluator 환경을 사용했다. Tier 1에는 섹션명·추가 metadata·설명 길이 등 비차단 권고가 남았다. 원본 보고서는 로컬 임시 디렉터리에 두고, 릴리스 평가 자료에는 요약을 넣는다. 정적 점수는 실제 UI 품질 측정치가 아니다.

### 실제 브라우저 결과

설치된 Chrome 152.0.7977.82를 별도 임시 프로필과 loopback 서버로 실행했다. 저장소의 결함 fixture를 서로 격리된 복사본으로 만들고, 같은 TASK.md·동일 부모 설정을 상속한 Codex native 에이전트 두 개에 2.0.0과 2.1.0 지침을 각각 제공했다. 모델의 별도 식별자나 비공개 sampling 값은 추정하지 않고 동일 세션 상속으로 기록했다.

| 대상 | 외부 동작 검사 | 관찰 |
| --- | --- | --- |
| 수정 전 결함 fixture | 3/8 통과, 5개 의도된 실패 | 실패한 저장의 초안·상태·재시도, IME Enter, 검색 히스토리 문제 탐지 |
| 2.0.0 지침을 적용한 결과 | 8/8 통과 | 모든 관찰된 결함 복구, 정상 저장·일반 Enter 유지 |
| 2.1.0 지침을 적용한 결과 | 8/8 통과 | 모든 관찰된 결함 복구, 정상 저장·일반 Enter 유지 |
| 모든 Enter를 차단한 변이 대조군 | 7/8 통과, 일반 Enter만 실패 | IME 방어가 일반 키보드 제출을 깨뜨리는 회귀도 탐지 |

기존·새 결과에서 각각 1280px 화면, 긴 한국어 초안과 오류를 표시한 375px 화면, 키보드 포커스 화면을 직접 열어 확인했다. 브랜드 역할과 기존 구조가 유지되었고 오류는 패널 안에서 줄바꿈됐다. Tab으로 검색·편집·저장에 접근했으며 저장 버튼의 포커스 링을 확인했다. 긴 제목은 원래의 단일 행 입력 안에서 편집 가능한 전체 값으로 유지되며 스크린샷에 모든 글자가 한꺼번에 보인다는 뜻은 아니다.

비교 결과는 `pass`, 관찰된 개선 0건·회귀 0건이다. **이 단일 사례에서 새 버전의 우월성은 입증되지 않았다.** 이번 릴리스는 재사용 가능한 디자인 판단과 구체적인 검증 절차를 보강하며, 더 다양한 제품·모델에서의 효과는 추가 비교가 필요하다.

초기 fixture SHA-256: `02578989912ac20e5054827df3fb0424adeba98d222fa72461d923a1b547b87e`.
후보 스킬 전체 snapshot SHA-256: `bc7367f95fa761ecbf0f042ebc97f10ccb599ac35a0f28f7a98557d0860de02a`.
각 해시는 정렬된 상대경로·NUL·파일 내용·NUL을 이어 계산한다. 실제 검사 JSON, 비교 결과, 화면, 변경 diff, 스킬 snapshot은 GitHub 릴리스의 별도 평가 자료에 포함한다. 에이전트가 보고한 요약은 독립 검사와 구분하며, 전체 도구 호출 transcript는 포함하지 않는다.

독립 검토에서 발견한 일반 Enter 성공 경로 누락과 좁은 화면 오류 상태 누락을 보완했다. 드라이버는 실제 브라우저 키 입력으로 일반 Enter를 확인한다. 비교기는 관찰된 실패가 있으면 미실행 항목보다 먼저 changes-required를 반환한다.

### 한계

- IME 검사는 합성 composition 이벤트로 handler를 확인했다. 실제 OS 한글 입력기·물리 기기·스크린리더는 검증하지 않았다.
- 브라우저 동작과 화면 관찰을 별도 기록했다. 화면 캡처나 모델 자체 보고만으로 동작 통과를 판단하지 않았다.
- 호스트의 자동 스킬 발견은 별도 미검증이다. 이번 에이전트는 지정한 스킬 snapshot을 명시적으로 읽었다.
- 비교기는 기록의 구조와 비교 가능성을 검증하며 증거 자체의 진실성을 자동 보증하지 않는다.
- Tier 2/3와 전용 보안 스캐너는 미실행이며 Tier 1을 완전한 보안 감사로 해석하지 않는다.
- 설치기의 동시 실행·강제 종료 복구는 검증하지 않았다. 여러 스킬 설치 전체의 원자성을 보장하지 않는다.
- npm 런타임은 Node 20 이상과 Python 3.9 이상이다. 선택적 브라우저 평가 드라이버는 Node 22 이상과 기존 Chrome이 필요하다. 검증 환경은 macOS/Node 25.2.1/npm 11.7.0이며 Windows 실행은 미검증이다.
- 이 문서의 검증 결과는 npm 레지스트리 게시 성공의 증거가 아니다. 실제 게시 상태는 릴리스 안내에 별도로 기록한다.
