## Prompt

Use case: brand-identity and editorial illustration.
Asset type: finished wide 3:1 GitHub README brand banner for an open-source UI/UX skill set named LUTRIVA.
Create a polished original identity with quiet character and deliberate craft.
Composition: wide landscape 1800 by 600-ish, generous safe margins. Left 48% is restrained typography, right 52% is one sculptural ivory river otter moving fluidly through a single continuous teal current. The otter is elegant, clearly recognizable with small rounded ears, short muzzle and tapering tail, side/three-quarter view facing left, neither fox nor seal. Its curved body and the river contour express smooth interaction. Keep everything comfortably inside the frame.
Style: refined editorial engraving meets cut-paper relief, subtle fine line work and softly dimensional ivory surfaces. Grown-up, tactile, collectible book-cover quality. Dark inky river green #102B2B background, bone ivory #F1ECDF figure/type, muted jade #78BAA0 current, very sparing pale brass #CAB788 details. Calm diffuse lighting; no shiny plastic.
Text exactly: large uppercase “LUTRIVA” in confident widely tracked custom serif typography, below it smaller “Interfaces, at ease.”, below that very small but readable “UI / UX SKILLS FOR CODEX & CLAUDE CODE”.
Keep text flat, crisp, unwarped, all on the left. No extra words. Elegant hierarchy and enough contrast to read when the banner is 800px wide.
The composition must feel authored and balanced with ample negative space. No neon, no purple gradient, no circuit boards, no UI cards, no dashboards, no starbursts or fake metrics, no watermarks. Full-bleed fixed dark background. This is a standalone brand image, not a screenshot of a website.
